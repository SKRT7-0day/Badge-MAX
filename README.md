# 🚀 Discord Badge & Playtime Auto-Farm

🌐 [English](README_EN.md) | **العربية**

سكربت لأتمتة ساعات اللعب والمطالبة بشارات ديسكورد.

> ⚠️ **للأغراض التعليمية فقط.** قد يخالف شروط خدمة ديسكورد (ToS) ويعرّض حسابك للحظر. استخدمه على مسؤوليتك.
> 🔒 بعد الانتهاء **غيّر كلمة مرور حسابك** لإبطال التوكن القديم، ولا تشارك التوكن مع أحد.

---

## ⚡ التشغيل السريع

**📱 Termux (أندرويد)**
```bash
pkg update -y && pkg upgrade -y && pkg install python git -y && pip install requests websocket-client && python main.py
```

**💻 كمبيوتر (PC)**
```bash
pip install requests websocket-client && python main.py
```

## 🛠️ استخراج التوكن والكوكيز

> 🔑 **ما هو التوكن؟** نص طويل يعمل مثل كلمة مرور حسابك. من يملكه يدخل حسابك دون كلمة مرور. **لا ترسله ولا تنشره ولا تضعه إلا في السكربت.**

الكود المستخدم لجلب التوكن (نفس الكود في كل الطرق):
```javascript
window.webpackChunkdiscord_app.push([[Math.random()],{},e=>{for(const c of Object.values(e.c))if(c?.exports?.default?.getToken!==void 0)copy(c.exports.default.getToken())}]);
```

### 💻 أولاً: على الكمبيوتر (PC)

**1) فتح ديسكورد في المتصفح**
- افتح **Chrome** أو **Brave**، وادخل على [discord.com/app](https://discord.com/app).
- سجّل الدخول، وانتظر حتى تظهر السيرفرات والمحادثات كاملة (لا تكمل قبل أن يكتمل التحميل).

**2) فتح أدوات المطور**
- اضغط `F12` (أو `Ctrl + Shift + I`). على ماك: `Cmd + Option + I`.
- تظهر لوحة في جانب الصفحة أو أسفلها، فيها تبويبات في الأعلى مثل Elements وConsole وNetwork وApplication.

**3) استخراج التوكن**
1. اضغط على تبويب **Console**.
2. إذا كتب المتصفح أن اللصق محظور، اكتب `allow pasting` ثم `Enter`، وبعدها يسمح لك باللصق.
3. الصق الكود أعلاه واضغط `Enter`.
4. ستظهر غالباً كلمة `undefined`. **هذا طبيعي** ولا يعني فشل العملية. التوكن صار منسوخاً في الحافظة.
5. الصقه مباشرة (`Ctrl + V`) في ملاحظات أو في المكان الذي يطلبه السكربت.
6. شكله نص طويل من 3 أجزاء يفصل بينها نقطتان، مثل `xxxx.yyyy.zzzz`.

> ⚠️ ديسكورد يعرض في الكونسول رسالة حمراء "Stop!" تحذّر من لصق الأكواد. هذا تحذير عام، ولا تلصق في الكونسول أي كود لا تفهمه أو لا تثق بمصدره.

**4) استخراج الكوكيز**
1. من نفس لوحة المطور اضغط تبويب **Application**. إذا لم تجده اضغط السهمين `»` لإظهار بقية التبويبات.
2. في القائمة اليسرى افتح **Cookies** ثم اضغط على `https://discord.com`.
3. في الجدول ابحث في عمود **Name** عن `__dcfduid` (وإن لم تجده فابحث عن `__sdcfduid`).
4. اضغط مرتين على خانته في عمود **Value** لتحديدها، ثم `Ctrl + C` للنسخ.

### 📱 ثانياً: على الأندرويد (Kiwi Browser)

**1) تثبيت المتصفح**
- حمّل ملف APK لـ **Kiwi Browser** من [GitHub Releases](https://github.com/kiwibrowser/src.next/releases).
- عند التثبيت اسمح لتطبيق المتصفح/الملفات بـ "التثبيت من مصادر غير معروفة".

**2) فتح ديسكورد**
- افتح Kiwi وادخل على [discord.com/app](https://discord.com/app).
- إذا ظهر لك خيار فتح التطبيق، اختر **المتابعة في المتصفح** (Continue in browser).
- سجّل الدخول وانتظر اكتمال التحميل.

**3) تفعيل موقع سطح المكتب**
- اضغط النقاط الثلاث `⋮` أعلى المتصفح، ثم فعّل **Desktop site**. بدونه يحاول ديسكورد فتح التطبيق ولا تعمل الأدوات جيداً.

**4) فتح أدوات المطور واستخراج التوكن**
1. اضغط `⋮` ثم **Developer tools** (أدوات المطور).
2. اضغط تبويب **Console**.
3. اكتب `allow pasting` ثم `Enter` إذا حُظر اللصق.
4. الصق الكود أعلاه واضغط Enter. سيظهر `undefined`، وهذا طبيعي والتوكن صار في الحافظة.
5. الصقه في ملاحظات أو مباشرة في Termux (اضغط مطولاً على الشاشة ← Paste).

**5) استخراج الكوكيز**
1. في شريط التبويبات أعلى أدوات المطور، اضغط أيقونة **السهمين `>>`** في أقصى اليمين (بجوار تبويب **Performance**) لإظهار بقية التبويبات.
2. اختر **Application** (التطبيق) من القائمة المنسدلة.
3. من القائمة الجانبية اليسرى وسّع قسم **Storage** (التخزين)، ثم اضغط على **Cookies**.
4. اضغط على `https://discord.com` لتظهر ملفات تعريف الارتباط الخاصة بديسكورد.
5. ابحث في عمود **Name** عن `__dcfduid` (أو `__sdcfduid`)، واضغط على قيمته في عمود **Value** لتحديدها ثم انسخها.

### 🧩 مشاكل شائعة في هذه المرحلة
| المشكلة | الحل |
|---|---|
| الكونسول يرفض اللصق | اكتب `allow pasting` ثم `Enter` |
| يظهر خطأ مثل `Cannot read properties` | أعد تحميل الصفحة، وانتظر اكتمالها، وجرّب من جديد |
| الصق فلا يظهر شيء أو يظهر `undefined` | هذا طبيعي. جرّب `Ctrl + V` في ملاحظات لترى هل نُسخ التوكن |
| لم ينسخ التوكن أبداً | ديسكورد يحدّث موقعه أحياناً فيتعطل الكود. استخدم الطريقة البديلة في فيديو Euiz أعلاه |
| لا أجد `__dcfduid` | ابحث عن `__sdcfduid`، أو أعد تحميل الصفحة وافتح تبويب Application من جديد |

> 🔒 **تذكير:** بعد انتهاء استخدام السكربت غيّر كلمة مرور حسابك، فهذا يبطل التوكن القديم.

## 📱 التشغيل على الهاتف (Termux)
حمّل Termux من [F-Droid](https://f-droid.org/packages/com.termux/) (نسخة Play Store قديمة).

إن لم تنزّل المشروع بعد:
```bash
git clone <رابط-المستودع> && cd <اسم-المجلد>
```

### 📖 شرح الأوامر
| الأمر | ماذا يفعل؟ |
|---|---|
| `pkg update -y` | يحدّث قائمة الحزم |
| `pkg upgrade -y` | يرقّي الحزم المثبتة |
| `pkg install python git -y` | يثبّت Python وGit |
| `pip install requests websocket-client` | يثبّت مكتبات الاتصال |
| `python main.py` | يشغّل السكربت |

- `&&` تربط الأوامر: كل أمر ينفّذ فقط إذا نجح السابق.
- `-y` يوافق تلقائياً على أسئلة التأكيد.

### 🧩 أخطاء شائعة
- `No such file: main.py` ← ادخل مجلد السكربت بـ `cd`.
- فشل `pkg update` ← نفّذ `termux-change-repo`.
- `pip` غير موجود ← `pkg install python-pip -y`.
